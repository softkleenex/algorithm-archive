C - 긴 수열

시간 제한: 2초 / 메모리 제한: 1024 MiB

점수: 300점

## 문제 설명

정수 `N`, `K`와 `N`개의 정수 수열 `A₁, A₂, …, Aₙ`, 그리고 길이 `N`의 정수 수열 `C = (C₁, C₂, …, Cₙ)`이 주어진다.

수열 `Aᵢ`의 길이는 `Lᵢ`이고,

`Aᵢ = (Aᵢ,₁, Aᵢ,₂, …, Aᵢ,ₗᵢ)`

이다.

`1 ≤ K ≤ Σ(Cᵢ × Lᵢ)`가 보장된다.

다음 절차를 통해 `A`와 `C`로부터 정수 수열 `B = (B₁, B₂, …, B_{Σ(Cᵢ × Lᵢ)})`를 만든다.

1. 처음에 `B`는 길이 0의 빈 수열이다.
2. `i = 1, 2, …, N` 순서대로 다음을 수행한다.
   - 수열 `Aᵢ`를 `B`의 끝에 `Cᵢ`번 이어 붙인다.

완성된 수열 `B`에서 `B_K`의 값을 구하여라.

## 제약 조건

- `1 ≤ N`
- `1 ≤ ΣLᵢ ≤ 2 × 10⁵`
- `1 ≤ Aᵢ,ⱼ ≤ 10⁹` (`1 ≤ j ≤ Lᵢ`)
- `1 ≤ Cᵢ ≤ 10⁹`
- `1 ≤ K ≤ Σ(Cᵢ × Lᵢ)`
- 모든 입력값은 정수이다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어진다.

```text
N K
L₁ A₁,₁ A₁,₂ … A₁,ₗ₁
L₂ A₂,₁ A₂,₂ … A₂,ₗ₂
⋮
Lₙ Aₙ,₁ Aₙ,₂ … Aₙ,ₗₙ
C₁ C₂ … Cₙ
```

## 출력

정답을 출력하여라.

## 예시 1

```text
입력
3 9
3 1 3 2
1 3
2 4 3
1 3 2

출력
4
```

`B`는 다음과 같이 만들어진다.

- 처음: `B = ()`
- `A₁ = (1, 3, 2)`를 1번 붙인다.
  - `B = (1, 3, 2)`
- `A₂ = (3)`을 3번 붙인다.
  - `B = (1, 3, 2, 3, 3, 3)`
- `A₃ = (4, 3)`을 2번 붙인다.
  - `B = (1, 3, 2, 3, 3, 3, 4, 3, 4, 3)`

따라서 `B₉ = 4`이므로 `4`를 출력한다.
